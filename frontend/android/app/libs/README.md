# Start.io SDK Directory

## ⬇️ Download SDK

1. Go to your Start.io Publisher Dashboard
2. Download the Android SDK (.aar file)
3. Place it in this `libs` folder

## 📁 Expected File

The SDK file should be named something like:
- `startio-sdk-5.15.3.aar` (version number may vary)

## 🔧 After Adding SDK

Update `android/app/build.gradle.kts` with the correct SDK version name in the dependencies section.
